# 게임 개발 노트

게임 개발 블로그. 갈래는 넷 — 개발일지(`log`) · 개발 노하우(`knowhow`) · 인사이트(`insight`) · 기타(`etc`).
깃허브 페이지가 `docs/` 폴더를 그대로 보여 준다.

## 글 더하기
1. `posts/2026-11-23-주소에-쓸-이름.md` 파일을 하나 만든다. 꼴은 `posts/_template.md` 를 베낀다.
2. `python3 build.py` — `docs/` 를 다시 만든다(파이썬만 있으면 된다).
3. `docs/` 까지 같이 커밋하고 올린다.

미리 보기: `python3 build.py --drafts && python3 -m http.server 8731 -d docs` → `http://localhost:8731/`
(`--drafts` 는 이름이 `_` 로 시작하는 글과 `draft: true` 인 글도 넣는다. 올리기 전에는 `--drafts` 없이 다시 굽는다.)

## 구조
| 곳 | 하는 일 |
|---|---|
| `posts/*.md` | 글. 파일 하나 = 글 하나 |
| `static/` | 그대로 복사되는 것. 그림은 `static/img/` |
| `theme/` | 화면 스타일(`style.css`)과 밝게 · 어둡게 단추(`app.js`) |
| `site.json` | 블로그 이름 · 한 줄 소개 · 갈래 · 공개 주소 |
| `build.py` | 굽는 스크립트 |
| `docs/` | 구운 결과(손으로 고치지 않는다) |

## 올리지 않는 것
게임의 코드 · 데이터 · 자산 원본(스프라이트 · 배경 · 아이콘)과 다른 게임의 스크린샷은 올리지 않는다.
그림이 필요하면 우리 게임 화면 캡처만 쓴다.
